# Как перейти с Element на VaVsta Messenger и не потерять переписки

Это инструкция для пользователей `chat.vavsta.ru`, которые сейчас сидят в классическом
приложении **Element** (Android) и хотят перейти на **VaVsta Messenger**.

## Главное, что надо понять

VaVsta Messenger — это тот же Matrix. Переписки хранятся **на сервере**, при установке
нового приложения они не исчезнут. Логин/пароль те же (`@user:chat.vavsta.ru`).

Риск потерять — только **зашифрованные** сообщения (сквозное шифрование). Чтобы новая
программа могла их прочитать, ей нужны ключи шифрования. Есть ровно два законных пути их
получить:

1. **Key Backup** — серверная резервная копия ключей, открывается вашим *ключом
   восстановления* (recovery key) или паролем.
2. **Подтверждённое старое устройство** — вход подтверждается со старого доверенного
   Element, и ключи «перекочёвывают» на новое устройство (cross-signing).

> ⚠️ **Важный нюанс.** VaVsta Messenger (как и Element X) **не умеет импортировать**
> файлы ключей `.keys`, которые классический Element экспортирует в файл. Рассчитывать
> надо только на Key Backup / recovery key, а не на экспорт в файл.

## Шаг 1. В старом Element проверьте Key Backup (до установки!)

1. Element → **Настройки** → **Безопасность и конфиденциальность** → **Шифрование**.
2. Раздел **Key Backup** (Бэкап ключей):
   - статус «Выполняется» — отлично; убедитесь, что у вас сохранён **ключ
     восстановления** (security key). Если нет — нажмите про него и запишите.
   - статус «Отключён» — **создайте бэкап**: «Настроить Key Backup», задайте парольную
     фразу или сгенерированный ключ и сохраните key в надёжном месте (бумага,
     менеджер паролей).
3. В идеале проверьте ключ на практике: восстановите его обратно (Element сам это умеет
   кнопкой восстановления). Если ключ не подходит — создайте новый и запишите заново.

Без работающего Key Backup и без старого устройства зашифрованная история **не
восстанавливается в принципе** — об этом подробнее внизу.

## Шаг 2. Установите VaVsta Messenger

Скачайте APK (страница `/mobile_guide/` на `chat.vavsta.ru` или раздел Releases на
GitHub). Устанавливается поверх или параллельно с Element — можно оставить оба.

## Шаг 3. Войдите и восстановите ключи

1. Откройте VaVsta Messenger.
2. Сервер уже подставлен — **chat.vavsta.ru**. Введите логин и пароль.
3. Сразу после входа приложение предложит **восстановить ключи**. Выберите:
   - **ввести ключ восстановления** (recovery key) — надёжнее всего; или
   - **ввести пароль аккаунта** — тоже открывает Key Backup.
4. Ни в коем случае не жмите «Пропустить», если хотите сохранить доступ к старой
   истории. Пропустили — вернуться можно позже: **Настройки → Безопасность →
   Шифрование → Восстановить**.

## Шаг 4. Подтвердите новое устройство (cross-signing)

После входа VaVsta может предложить **подтвердить это устройство**:

- в старом Element откройте **Настройки → Безопасность → Сессии** (или появится
  уведомление о новом устройстве);
- подтвердите вход: QR-код или эмодзи (сверить пары слов должны быть одинаковыми).

Так новое устройство становится доверенным, и ключи «переезжают» со старого телефона.

## Шаг 5. Проверьте историю

Откройте в VaVsta Messenger старый зашифрованный чат (общий с кем-то мутный, где было
много сообщений). Сообщения должны расшифроваться. Если расшифровываются — переезд
удался.

## Шаг 6. Попрощайтесь со старым приложением

Когда всё работает и техника проверена:

1. В старом Element: **Настройки → Безопасность и конфиденциальность → Сессии** —
   завершите сессию на этом телефоне (любые устройства можно отозвать).
2. Можете удалить Element. VaVsta Messenger останется работать один.

## Что если ничего не восстановить?

Если нет ни recovery key, ни старого доступа — расшифровать старые E2EE-сообщения
невозможно. Это свойство сквозного шифрования, обойти его нельзя (и никто на сервере
этого тоже не может — ключи не хранятся на сервере в открытом виде).

Что делать в таком случае:

- войти в аккаунт и **сбросить шифрование**: **Настройки → Безопасность →
  Шифрование → Сбросить** (удаляет старые ключи). Новые сообщения будут
  расшифровываться, старые останутся «зашифрованы» для всех новых устройств;
- переслать важные сообщения заранее с того устройства, где они ещё видимы.

## Миграция для десктопа (VaVsta Web)

Тот же принцип: зайдите на `chat.vavsta.ru` в браузере, войдите под своим логином и
восстановите ключи (recovery key или пароль). Сохранённый Key Backup работает на любом
количестве устройств.
